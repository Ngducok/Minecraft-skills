# Benchmark evidence status

No measured LLM pass rate or token usage has been established for this repository.

Previous claims of 90.3%, 87.1% and 85.5% were hardcoded in local report generators. Quality, ROI and turn improvements came from heuristic constants rather than recorded agent runs. These claims are withdrawn and must not be cited as empirical results.

The repository provides 62 skill evaluation scenarios. Scenario documents and offline checks are not evidence of passed LLM evaluations. File character/byte counts are not consumed tokens.

Follow [experimental protocol](EXPERIMENTAL_PROTOCOL.md) before publishing model comparisons. Retain exact settings, frozen inputs, paired execution logs, independent evaluations and provider/host token usage. Missing evidence remains unknown; never replace it with estimates or assumed passes.

Executable benchmark tooling and local test artifacts are not published in this docs-only update. Any future results must include traceable evidence; no cross-model ranking or Skill ROI is currently supported.
