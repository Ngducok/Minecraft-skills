# Datapack formats

The exact-release matrix records major/minor formats sourced from Mojang release notes. Since the 1.21.9 metadata change, use target-matched min_format/max_format; do not apply legacy pack_format-only templates universally. Namespace paths and schemas also change independently. JSON parsing alone does not prove Minecraft accepts functions, loot or recipes. Load a disposable matching world and inspect reload logs.
