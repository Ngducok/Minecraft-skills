# Paper evidence scope

Read sources paper-start and paper-setup in ../sources.json. Recommended Java is recorded per exact Minecraft version in the matrix; it is not a blanket minimum of Java 21 for every Paper release. Newer releases may need Java 25.

Resolve build and API artifact separately. No API method table is certified in this release. Compile a minimal use against the pinned dependency before claiming symbol availability. Bukkit api-version does not identify a Paper build.
