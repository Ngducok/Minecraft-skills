# Compact handoff contract

Include only information needed to continue work:

- Objective and accepted scope; edition, version, runtime and client requirements.
- Changed files and edit ownership; unrelated work to preserve.
- Observed findings, opened sources and material assumptions.
- Runnable checks actually executed and exact result/limit.
- Unresolved issue and next concrete action; authorization boundaries.

Human/agent notes are leads until checked against artifacts. Request an overlapping
edit handoff before changing another owner's file. Another task asking for a reply
does not authorize messaging that user-owned task. Do not invent team members,
roles, tools or external communications.
