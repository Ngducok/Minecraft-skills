# Playable-space checks

| Space | Required check | Common false proof |
| --- | --- | --- |
| Survival start | Renewable first loop and recovery | Chest exists |
| Competitive arena | Spawn timing, sightlines, alternate routes | Geometry is symmetric |
| Adventure map | Reachable objectives and save/checkpoint return | Route works in creative |
| Creative plot | Edit boundary, undo, template separation | Plot looks empty |
| Movement course | Intended ability/collision and checkpoint state | Spectator flythrough |
| Technical build | Target-runtime update/transfer behavior | Matching block screenshot |

Use only rows relevant to the requested mode. Test actual participant state, not
administrator permissions. Verify schematic origin, block entities and inventory
contents when importing templates. Reset scope must exclude other players' work.
