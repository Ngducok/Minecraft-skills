# Gemini loading

Use the host's documented project skill directory `.gemini/skills/<skill-name>/`. Read [official host documentation](https://geminicli.com/docs/cli/skills/) for installed-version discovery behavior. Load a selected canonical folder, preserving supporting files. Manual explicit loading is the fallback; no provider API or host-specific invocation extensions are required by the canonical instructions.

See ../README.md for copy/link boundaries. Native host loading has not been exercised by repository unit tests.
